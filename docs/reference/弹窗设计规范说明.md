## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **无分割线** | 去除 Header / Footer 之间的灰色横线，用留白（Whitespace）代替物理边界定义区块层级 |
| **呼吸感优先** | 内部间距遵循 4px / 8px 倍数步长，避免出现 13px、15px、18px 等随意数值 |
| **固定起点、弹性终点** | 弹窗顶部位置固定，高度随内容自适应，超出时由 `max-height` 兜底并触发内部滚动 |
| **三段式结构** | Header（固定）+ Body（弹性滚动）+ Footer（固定），无论内容多少，标题与操作按钮始终可见 |

## 2. 外框布局规范

### 2.1 核心数值（以 1000px 视口高度为基准）

| 属性 | 数值 | 说明 |
|------|------|------|
| 顶部留白 | `100px`（`10vh`） | 固定，视线定位点，弹窗始终从此处起始 |
| 最大总高度 | `calc(100vh - 160px)` | 保证底部至少保留 **60px** 对称安全区 |
| 底部留白（内容未填满） | 随内容自适应 | 弹窗高度收缩，留白灵活 |
| 底部留白（内容超出） | 固定 **60px ～ 80px** | 触发 `max-height`，内部滚动，底部安全区不变 |
| 弹窗宽度 | `520px`（常规） / `640px`（复杂表单） | `max-width: 90vw` 保证小屏适配 |
| 圆角 | `12px` | 对应 Semi / Arco 大圆角风格 |

> **数学验证**：`顶部 100px + 弹窗最大高度 (100vh - 160px) = 100vh - 60px`，底部恰好剩余 **60px**，完美对称。

### 2.2 定位方式

```css
/* 推荐：fixed + transform 水平居中 */
.modal-card {
  position: fixed;
  top: 100px;                        /* 10vh，固定顶部距离 */
  left: 50%;
  transform: translateX(-50%);

  width: 520px;
  max-width: 90vw;
  max-height: calc(100vh - 160px);   /* 核心约束 */
}
```

> 小屏适配建议将 `top` 改为 `clamp(40px, 10vh, 100px)`，在 600px 以下视口自动收缩顶距。

### 2.3 遮罩层

```css
.modal-overlay {
  position: fixed;
  inset: 0;
  background: rgba(29, 33, 41, 0.4);   /* Semi 推荐遮罩色 */
  display: flex;
  flex-direction: column;
  align-items: center;
  padding-top: 100px;                  /* 与弹窗顶距一致 */
  z-index: 1000;
}
```

## 3. 内部结构规范

### 3.1 三段式布局

```
┌─────────────────────────────────────┐
│  Header   标题 + 关闭 Icon           │  ← flex-shrink: 0（不压缩）
├─────────────────────────────────────┤
│                                     │
│  Body     表单内容区（可滚动）        │  ← flex: 1 1 auto; overflow-y: auto
│                                     │
├─────────────────────────────────────┤
│  Footer   取消 + 确定               │  ← flex-shrink: 0（不压缩）
└─────────────────────────────────────┘
```

### 3.2 Flex 结构代码

```css
.modal-card {
  display: flex;
  flex-direction: column;
  max-height: calc(100vh - 160px);
}

.modal-header,
.modal-footer {
  flex-shrink: 0;    /* 头尾不随内容压缩 */
}

.modal-body {
  flex: 1 1 auto;
  overflow-y: auto;  /* 仅内容区滚动 */
}
```

## 4. 间距 Token 规范

项目内统一使用以下 CSS 变量，禁止在弹窗内使用未列出的随意数值：

```css
:root {
  --space-xs:  8px;   /* 亲密间距：Label 与控件之间 */
  --space-sm: 12px;   /* 标题区底部到正文起始 */
  --space-md: 16px;   /* 子模块标题、Footer 缓冲 */
  --space-lg: 24px;   /* 表单项之间、容器内边距 */
}
```

| Token | 数值 | 使用场景 |
|-------|------|---------|
| `--space-xs` | `8px` | Label → Input / Select 之间 |
| `--space-sm` | `12px` | Header 底部 → Body 第一个字段 |
| `--space-md` | `16px` | 子模块标题下方、Footer 顶部缓冲 |
| `--space-lg` | `24px` | 表单项之间（纵向间距）、容器四周 Padding |

## 5. 组件间距细则

### 5.1 Header 区

```css
.modal-header {
  padding: 24px 24px 12px 24px;
  /* 上: 24px  左右: 24px  下: 12px（上松下紧，与正文拉开节奏）*/
  font-size: 18px;
  font-weight: 600;
  color: #1D2129;
  display: flex;
  align-items: flex-start;
  justify-content: space-between;   /* 标题左，关闭 Icon 右 */
}
```

### 5.2 Body 区

```css
.modal-body {
  padding: 4px 24px 20px 24px;
  /* 上: 4px（配合 Header 12px 底距，视觉合计 16px）*/
  /* 下: 20px（为 Footer 留缓冲）*/
  overflow-y: auto;
  font-size: 14px;
  line-height: 1.6;
  color: #4E5969;
}
```

### 5.3 表单项

```css
.form-item {
  margin-bottom: 24px;   /* 字段间距 */
}

.form-item:last-child {
  margin-bottom: 0;      /* ⚠️ 末项清零，避免与 Footer padding 叠加 */
}

.form-item .label {
  display: block;
  font-size: 14px;
  color: #1D2129;
  margin-bottom: 8px;    /* Label → 控件亲密间距 */
}

.form-item input,
.form-item select {
  height: 32px;
  width: 100%;
  padding: 0 12px;
  border-radius: 6px;
  border: 1px solid rgba(0,0,0,0.12);
  background: rgba(0,0,0,0.04);
  font-size: 14px;
}
```

### 5.4 Footer 区

```css
.modal-footer {
  padding: 16px 24px 24px 24px;
  /* 上: 16px（缓冲）  下: 24px（对称底部内边距）*/
  display: flex;
  justify-content: flex-end;
  gap: 12px;
  flex-shrink: 0;
}
```

├ · · · · · · · · · · · · · · ·│ ← 无分割线
│ ↕ 4px  (Body padding-top)    │
│                               │

│ ↕ 20px (Body padding-bot)    │

## 6. 复杂表单场景

### 6.1 子模块标题（分组标题）

当表单内容较多、需要分组时（如「基础信息」「位置信息」），使用子模块标题：

```css
.section-title {
  font-size: 14px;
  font-weight: 600;
  color: #1D2129;
  margin-top: 24px;    /* 与上方字段的间距（上疏） */
  margin-bottom: 16px; /* 与下方字段的间距（下密） */
}

/* 第一个 section-title 无需上间距 */
.section-title:first-child {
  margin-top: 0;
}
```

> **口诀**：子标题「上 24 / 下 16」，上疏下密强化字段归属感。标题明确属于它**下方**的那组字段，而不是悬在中间。

### 6.2 双列布局

```css
.form-row {
  display: grid;
  grid-template-columns: 1fr 1fr;
  column-gap: 16px;   /* 横向间距，小于纵向 24px，网格感更清晰 */
  row-gap: 24px;      /* 纵向间距，与单列保持一致 */
}
```

> 横向 `column-gap: 16px` < 纵向 `row-gap: 24px`，两者错开，用户视线更容易横向关联同行字段。

### 6.3 必填项标记

```css
.label-required::before {
  content: '*';
  color: #f53f3f;   /* 错误/必填红，对应 Semi/Arco 语义色 */
  margin-right: 4px;
}
```

## 7. 按钮规范

### 7.1 尺寸

| 类型 | 高度 | 横向 Padding | 圆角 | 字号 |
|------|------|-------------|------|------|
| 常规按钮 | `32px` | `16px` | `6px` | `14px` |
| 小按钮 | `28px` | `12px` | `6px` | `13px` |

### 7.2 颜色

```css
/* 确认 / 主操作 */
.btn-primary {
  background: #4361ee;
  color: #ffffff;
  border: none;
}
.btn-primary:hover {
  background: #3651d4;   /* 加深 ~8%，提供 hover 反馈 */
}
.btn-primary:active {
  background: #2d44c4;
}

/* 取消 / 次操作 */
.btn-secondary {
  background: rgba(0, 0, 0, 0.04);
  color: #1D2129;
  border: 1px solid transparent;
}
.btn-secondary:hover {
  background: rgba(0, 0, 0, 0.08);
}

/* 危险操作（如删除确认弹窗） */
.btn-danger {
  background: #f53f3f;
  color: #ffffff;
}
.btn-danger:hover {
  background: #d93025;
}
```

### 7.3 排列顺序

- **常规弹窗**：`[取消]` `[确定]` —— 次操作在左，主操作在右
- **危险确认弹窗**：`[取消]` `[删除]` —— 危险操作用红色主按钮

## 8. 关闭 Icon 规范

### 8.1 位置

关闭 Icon 始终位于 Header **最右侧**，与标题文字通过 `justify-content: space-between` 对齐。

### 8.2 样式

```css
.close-btn {
  width: 28px;
  height: 28px;
  border: none;
  background: transparent;
  border-radius: 6px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: #86909C;            /* 静态态：三级文字色 */
  cursor: pointer;
  margin: -4px -6px 0 0;    /* 视觉上贴近右上角 */
  transition: background 0.15s, color 0.15s;
  flex-shrink: 0;
}

.close-btn:hover {
  background: rgba(0, 0, 0, 0.04);   /* 浅灰 hover 底色 */
  color: #1D2129;                    /* hover 变深 */
}
```

### 8.3 SVG Icon

```html
<button class="close-btn" aria-label="关闭">
  <svg width="16" height="16" viewBox="0 0 16 16" fill="none">
    <path
      d="M3.5 3.5 L12.5 12.5 M12.5 3.5 L3.5 12.5"
      stroke="currentColor"
      stroke-width="1.5"
      stroke-linecap="round"
    />
  </svg>
</button>
```

> 描边使用 `stroke="currentColor"`，颜色自动跟随父元素的 `color`，无需单独维护 hover 颜色。

## 10. 常见问题 & 避坑指南

### ❌ 问题一：底部按钮区「留白偏大」

**原因**：最后一个 `form-item` 的 `margin-bottom: 24px` 与 `.modal-footer` 的 `padding-top: 16px` 叠加，实际留白变为 40px。

**解决**：
```css
.form-item:last-child { margin-bottom: 0; }
```

---

### ❌ 问题二：长内容时关闭按钮或操作按钮被遮挡

**原因**：未使用 Flex 三段式布局，Body 没有设置 `overflow-y: auto`。

**解决**：确保弹窗容器为 `display: flex; flex-direction: column`，且 Header / Footer 设置 `flex-shrink: 0`，Body 设置 `flex: 1 1 auto; overflow-y: auto`。

---

### ❌ 问题三：不同弹窗上下留白视觉不一致

**原因**：各弹窗使用了不同的 `top` 值（如 `80px`、`120px`、`15%`）。

**解决**：统一使用 `clamp(40px, 10vh, 100px)` 作为顶距，配合 `max-height: calc(100vh - 160px)` 约束总高。

---

### ❌ 问题四：去掉分割线后内容区和按钮区视觉「糊」在一起

**原因**：滚动时无边界感，缺乏区分。

**解决**：可在 Body 内容发生滚动时，通过 JS 动态为 Footer 添加顶部微阴影：
```javascript
modalBody.addEventListener('scroll', () => {
  const atBottom = modalBody.scrollHeight - modalBody.scrollTop <= modalBody.clientHeight + 1;
  modalFooter.style.boxShadow = atBottom ? 'none' : '0 -1px 0 rgba(0,0,0,0.06)';
});
```

---

### ❌ 问题五：小屏（高度 ≤ 768px）顶部留白过大

**原因**：`top: 100px` 在低矮屏幕占比过高。

**解决**：
```css
padding-top: clamp(40px, 10vh, 100px);
```
在 600px 视口高度下自动收缩为 `40px`，在 1000px 视口保持 `100px`。

## 附：间距速查口诀

```
亲密元素靠 8px  →  Label 与控件之间
同级字段隔 24px →  表单项与表单项之间
跨级分区用「上 24 / 下 16」  →  子模块标题的节奏
容器四周统一 24px  →  Header / Body / Footer 左右内边距
末项清零交 Footer  →  form-item:last-child { margin-bottom: 0 }
```
