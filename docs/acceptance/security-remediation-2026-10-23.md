## 整改内容

| 项目 | 修改与验证 |
| --- | --- |
| F-02 | 头像限制 JPG/JPEG/PNG、2 MB；校验扩展名、MIME、字节结构及真实解码；重编码去元数据；隔离头像目录；清理非法历史头像与符号链接；正常、错误及 CORS 响应添加 nosniff。 |
| M-01 | 四个 meta 接口使用真实 IDE/burners 数据表；IDE 选项从接口获取；固定十种型号；名称 casefold 唯一及并发冲突 409；多余字段 400、非法型号 422；仅 meta 错误响应统一为 code/message/data。 |
| BUG-01 | 创建和再次执行先计算真实摘要、读取同制品最新成功基线；即时确认复用 ActionConfirmDialog；确认令牌绑定用户、摘要、基线、关键配置、脚本和设备修订，并有时效。旧报告入口接入同一再次执行流程，旧覆盖接口必须提交有效令牌。 |
| BUG-01 双失败 | 统一优先级为摘要计算失败、版本失败、完整性失败。授权确认版本差异后，完整性失败直接记录失败和 MD5/SHA256，不调度设备、回滚或重试。 |
| BUG-01 运行前 | 执行前重算摘要和基线，刷新账号、角色及权限；禁用、撤权、令牌版本变化、文件或关键配置变化均阻止覆盖。普通测试员 SQLite 回归覆盖这些场景。 |
| BUG-02 | 连接状态有 30 秒时效、focus 刷新、操作前强制探测和同项目请求共享；项目与请求身份防止陈旧响应回写；断连阻断在线入口，保留真实离线副本，恢复后刷新可用。 |
| BUG-03 | 明确的 local_exists=false 不再被路径覆盖；缺字段不由残留路径推定存在；提交前复查文件；明确选择本地来源后不得偷偷切到服务器副本或在线下载。 |
| BUG-04 | 新建和扫描仅支持固定十型号；历史 SWD 下载器只读兼容，不误映射成 PWLINK2；旧型号不再作为运行依赖诊断的新型号。 |
| O-01 | 确定性校验失败停止，不执行设备脚本、设备回滚或无意义重试。真实设备或网络失败保留原重试约定。 |
| 名称 | 登录页和主页左上角名称修改为“嵌入式安装性测试工具”。 |
| 头像与身份 | 用户、脚本、日志、任务、协议、仓库成员及邀请人传递公共身份与头像；共享 UserIdentity 展示及上传事件刷新；协议历史记录按用户名兼容。 |
| 错误提示 | 非法、损坏、超限头像显示可见错误；两次新密码不同显示“密码不一致”；修复表单未处理 Promise。 |
| 注入权限与删除 | 连接、执行、恢复统一使用 injection:add；终态删除使用原确认气泡，运行中禁止删除；验证取消不发请求、确认只发一次 DELETE。 |
| 脚本保存 | 基础编辑仅发送实际表单字段，不再将未提交的 content 写空；IDE 从 meta 接口读取。 |
| 回归附带修复 | 本机服务器存储与远端 Windows 路径分开处理；跨平台路径断言比较实际解析路径；TFTP 端口 0 正确使用系统分配端口，启动失败关闭套接字。 |
| 缺失资源 | 补齐 AL321 program_flash 参数与日志包装器、XDS510plus 只读驱动检查器；放行这两个脚本的 gitignore 规则，避免源码交付遗漏；通过静态调用契约测试，但尚未执行 Windows 实机烧录。 |

1. D1/D2 正文未取得，M-01 不能标为完整契约验收完成。
2. 20 项跳过覆盖 Windows 专用批处理、外部运行工具或硬件条件；跳过不计为通过。
3. 新补 PowerShell 脚本的静态测试通过，不代表 Windows PowerShell、厂商工具、驱动切换或实机写入已经验证；目标节点使用外部烧录器工具目录，部署时需同步这些脚本，不能只更新前端。
4. CodeArts 断连测试使用受控响应，未实际操作用户的线上 CodeArts 账号或进行真实下载故障演练。
5. 此前直接 SQL 写入临时任务时出现过制品关联丢失；正式 API 创建的非执行任务经过真实页面刷新后仍保留关联，实测通过。原临时写入现象未定位，不冒充已修复；未恢复用户删除的临时脚本。
6. 浏览器服务使用临时数据目录及测试许可证配置，验收后已停止隔离测试后端；前端开发服务保持运行。未切换为真实业务数据，也未发布、打包、提交或推送代码。最新后台代码需要在实际部署环境使用原制品主密钥重启后生效；当前 Shell 无原主密钥，不能为真实数据随意生成替代密钥。
7. 前端包体积、Pydantic 配置弃用、旧剪贴板 API 等警告不属于此次清单阻断项，仍是后续维护事项。
